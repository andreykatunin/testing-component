# OpenSpec

## Выполнение `/opsx:continue`

- Следуй команде, сгенерированной OpenSpec, и работай только над выбранным CLI
  артефактом.
- Артефакт создаётся после выполнения предусмотренных для него шагов анализа и,
  когда требуется, согласования. Наличие файла означает, что артефакт готов для
  зависимых этапов.
- После создания проверь OpenSpec status, сообщи результат пользователю и
  остановись. Не переходи к следующему артефакту в том же `/opsx:continue`.

## Взаимодействие с субагентами

- `business-analyst`, `system-analyst` и `qa-engineer` самостоятельно создают
  и изменяют принадлежащие им артефакты. Основной агент эти файлы не редактирует.
- Если субагент возвращает вопросы, передай их пользователю без изменения смысла,
  а полученные ответы — тому же субагенту для продолжения анализа.
- Не отвечай на вопросы роли за пользователя и не выбирай предложенный вариант
  без явного решения пользователя.
- Передавай субагенту согласованное содержание и обратную связь без добавления
  новых требований, решений или предположений.
- Не превращай предложения агента, best practices, молчание пользователя или
  неподтверждённые предположения в требования.

## Изменение существующих артефактов

- При смысловом изменении upstream-артефакта считай затронутые
  downstream-артефакты устаревшими и обновляй их в порядке зависимостей.
- Ролевой артефакт повторно анализирует и изменяет только его владелец.
- Не допускай одновременного изменения одного файла несколькими агентами.
